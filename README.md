# jietu

轻量原生截图与标注工具，面向 Windows 11 无独显迷你主机（纯 CPU 渲染，不依赖 GPU 合成）。
常驻几乎零开销（事件驱动，无轮询），按热键即用。

> 当前状态：**M0–M4 与 M5a 全部交付**（v0.2.0），下一步 M5 打磨（性能剖析、多屏测试、打包）。
> 需求见 `screenshot-tool-PRD.md`，决策见 `docs/adr/`。

## 功能

- **截图**：F1 触发，全屏冻结 → 框选（八向缩放、空格拖动、方向键微调）→ 复制 / 保存 / 贴图
- **标注**：矩形、直线/曲线箭头、文本（中文 IME、系统字体、粗体/斜体、字号）、荧光笔、高斯模糊、聚光灯
- **二次编辑**：选中对象显示包围框与八向手柄，拖动移动 / 缩放；工具栏颜色、线宽、填充、圆角、透明度实时作用于选中对象；`Shift` 约束（正方形 / 45° 方向 / 轴向锁定 / 等比）
- **撤销重做**：快照式撤销栈（100 步），一次拖拽 = 一步
- **输出**：剪贴板（CF_DIB + PNG）/ 另存为 PNG · JPEG · WebP（无损），文件名模板可选
- **长截图**：自动滚动 + 手动兜底，全重叠区一致性拼接，固定页眉页脚检测，可撤销最后一段
- **贴图（Pin）**：任意截图钉在屏幕，拖动 / 缩放 / 透明度 / 1px 蓝框 / 右键菜单，数量上限 20
- **设置面板**：自绘（深浅色跟随系统），开机自启、全部快捷键改键与冲突检测、贴图位置、文件名模板

## 快捷键

截图界面（覆盖层）：

| 按键 | 动作 |
|---|---|
| `Enter` / `Ctrl+C` / 选区内双击 | 复制到剪贴板并退出 |
| `Ctrl+S` | 另存为（PNG / JPEG / WebP） |
| `F3` | 把选区贴到屏幕 |
| `S` | 长截图（当前选区为视口） |
| `1`–`6` | 切换工具（矩形 / 箭头 / 文本 / 模糊 / 荧光笔 / 聚光灯，可改） |
| `Ctrl+Z` / `Ctrl+Y` · `Ctrl+Shift+Z` | 撤销 / 重做 |
| 方向键（`Shift` ×5） | 微调选中对象；无选中时移动选区框 |
| `Shift` + 拖动 | 正方形 / 箭头方向吸附 / 轴向锁定 / 等比缩放 |
| 按住空格 + 拖动 | 移动整个选区 |
| 滚轮 | 调线宽 / 模糊半径 / 字号（悬停对象或空白处） |
| `Esc` | 取消截图 |

贴图窗口：左键拖动、滚轮缩放、`Ctrl`+滚轮透明度、双击 / `Esc` 关闭、右键菜单、`Ctrl+F3` 边框开关、方向键移动。

全局热键（F1 截图 / F3 贴图）可在设置面板修改；无修饰键会抢占其他程序按键，建议 `Ctrl` / `Alt` 组合。

## 下载与使用

1. 从 [Releases](https://github.com/bd-dxg/jietu/releases) 下载 `jietu-v*-win-x64.zip`，解压到任意目录（绿色单文件，无需安装）
2. 双击 `jietu.exe`：程序**需要管理员权限**（否则无法覆盖其他管理员窗口，见 ADR 0003），首次运行会弹 UAC，请选择「是」
3. 启动后托盘常驻（无主窗口），按 `F1` 截图 / `F3` 贴图
4. 托盘左键打开设置（可改热键、开机自启、主题、文件名模板），右键为「设置 / 退出」
5. 配置与日志位置：`%APPDATA%\jietu\config.toml`

**首次运行提示**：exe 未做代码签名，Windows SmartScreen 可能提示「已保护你的电脑」——点「更多信息」→「仍要运行」。

## 构建与运行

```powershell
cargo run                 # 开发版（不提权，可调试）
cargo build --release     # 发布版（manifest 要求管理员权限，单文件）
cargo test                # 单测（136 项）
cargo fmt --check         # 格式化检查
cargo deny check          # 依赖许可证 / 安全公告 / 来源检查
```

依赖：Rust 1.98（edition 2024）、windows-rs 0.62、tiny-skia 0.12、serde、toml、png、jpeg-encoder、image-webp。

## 已知限制

- 发布版以管理员权限运行（覆盖 / 操作管理员窗口需要，见 ADR 0003）；开机自启走任务计划而非注册表
- 独占全屏游戏、DRM 保护内容可能抓到黑屏（系统限制）
- 一期界面仅简体中文，代码层预留 i18n
