# 7. 移除对象删除与层级调整

- **Status**: Accepted
- **Context**: PRD EDT-7（P0）原要求「颜色选择、线宽 / 字号调节、对象删除、层级调整」。M5a 阶段 B 按此实现了工具栏「置顶 / 置底 / 删除」按钮与 `Del` / `Ctrl+]` / `Ctrl+[` 快捷键。用户实测后判定：工具栏按钮偏多、层级调整用不到、误画的标注用 `Ctrl+Z` 撤销即可，要求把删除与层级整体下线。
- **Decision**:
  1. **完全移除**删除与层级调整：工具栏三个按钮与图标、`Action::Raise/Lower/Delete`、`Del` / `Ctrl+]` / `Ctrl+[` 快捷键、`Document::raise` / `lower` 与对应的 `Overlay` 方法一并删除。
  2. **同步修改 PRD**：§4.3 描述与 EDT-7 去掉「对象删除、层级调整」，改为「方向键微调选中对象位置」（同一轮交互打磨中新增）。
  3. 只删功能入口与实现，**不动**文本编辑清空时的对象移除路径（`Document::remove` 仍被 `overlay::textinput` 使用）。
- **Consequences**:
  - 更容易：工具栏回到 19 个元素（截图工具是「触发即用」，控件越少越好）；不再需要维护 z 序操作与它们的快捷键冲突检测。
  - 更难／代价：误画的标注**无法单独删除**，只能 `Ctrl+Z` 撤销，而撤销是栈式的——会连带撤销该对象之后的所有操作；对象层序此后只由绘制顺序决定，重叠对象无法调整先后。
  - 若日后恢复：可从 git 历史（PR #26，commit `7fcb914`）取回实现，但 PRD 条目与快捷键需一并恢复；本 ADR 的前提是「用户明确不需要该功能」，不是实现困难。
