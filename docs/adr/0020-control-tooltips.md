# ADR 0020：截图控件悬浮提示

- 状态：已采纳（v0.8.0 开发期，对应看板 #70）
- 影响范围：`overlay/toolbar`（新增 `tip` 子模块）、`overlay/wndproc`、`overlay/selection`（绘制层）、`overlay/mod`（hover 状态）、`overlay/objedit`（圆角手柄）、`overlay/interaction`、`overlay/ui`、PRD `EDT-10`
- 相关：ADR 0009（界面图标统一）、ADR 0010/0011（圆角控制柄）、ADR 0016（界面缩放）

## 背景

工具栏第一行 13 个按钮只有图标，没有文字。用户（issue #70）反馈「鼠标浮于工具栏上并无悬浮提示，
使用上很不清楚，需要学习成本」，并建议加悬浮提示开关、默认开启。

issue 里举了三个例子：悬停模糊组件显示「模糊工具」、悬停颜色显示「品红 + RGB」、悬停框选显示「框选工具」。

## 决策

1. **形态：水平对齐悬停控件、垂直贴工具栏外缘的小气泡**，不是常驻状态条。悬停到哪个按钮，
   气泡的水平中心就对准那个按钮，垂直方向贴整条工具栏的外缘（默认下方，下方塞不下则翻到上方），
   整体钳在屏幕内。
   垂直贴「整条工具栏」而非「按钮所在那一行」：文本工具下工具栏有两行，贴行内会被第二行字体控件挡住。
   圆角控制柄没有工具栏可言，两个方向都贴手柄自身。
   （开发期修订：初版把水平方向做成了「居中于整条工具栏」，悬停最左侧按钮时气泡离按钮很远；
   评审时改为跟随悬停控件。）
2. **出现时机：hover 立即给按钮底色，约 400ms 后出气泡**。鼠标快速扫过整排按钮时不会连续闪出提示；
   延迟期间按钮已有反馈，不显得卡。用一次性 `SetTimer`（400ms）实现：
   **只在 hover 目标变化时 `KillTimer` + `SetTimer` 一次**，鼠标在同一按钮内移动不重置计时，
   避免拖成高频定时器抖动。
3. **按下鼠标立即隐藏气泡并取消计时**。画标注、拖选区时若光标仍压在按钮上，气泡会一直挡视线。
4. **文案：`名称 · 快捷键`，能带就带**。工具键、长截图键、贴图键从配置现读（改键后提示跟着变）；
   撤销 / 重做 / 复制 / 保存带硬编码的 `Ctrl+Z` / `Ctrl+Y` / `Ctrl+C` / `Ctrl+S`；
   填充开关没有独立快捷键，只显示名称。
5. **不提供开关，始终开启**（偏离 issue 的建议，理由见下）。
6. **覆盖范围分批**。第一批：工具栏第一行 13 个按钮（6 工具 + 填充 / 撤销 / 重做 / 贴图 / 长截图 /
   复制 / 保存）+ 圆角控制柄（拖拽型手柄，只出气泡、不加底色）。第二批：长截图状态条。
   **不做**：颜色块（色名 / RGB 需要给 `editor::PALETTE` 补名字，属额外范围）、第二行字体控件、
   八向缩放手柄（形状已自解释）。
7. **实现复用现有命中体系**：工具栏已有 `hits: Vec<(SelRect, Action)>`，只需新增
   `Action → 文案` 映射与气泡几何，不新建一套命中区。hover 只在 `WM_MOUSEMOVE` 里做一次 `hit()`；
   脏区仅重绘「旧按钮 ∪ 新按钮」与气泡矩形，走现有 `Overlay::repaint()`。

## 为什么不加开关

issue 建议「加开关，默认开启」，这里不采纳，理由：

1. **提示本身就是低干扰形态**：延迟 400ms + 必须停在按钮上才出现，且鼠标一移开立即消失，
   不存在常驻遮挡。加开关防的是「一直显示的提示」，而这个方案不是。
2. **关掉之后再也不知道按钮是什么**：开关一旦被关，新用户又回到 issue 描述的原始问题，
   与加提示的初衷矛盾。宁可少一个配置项，也不留一个「把帮助关掉」的入口。
3. **设置面板膨胀是真实成本**：外观页已有主题 + 6 档界面缩放，通用页有 4 行。轻量定位下，
   每个「可关掉的体验细节」都该经得起「用户真的会关吗」的追问。

## 性能红线例外

「待机 0% CPU / 无定时器」红线针对**常驻状态**。本方案的 `SetTimer` 满足：

- 只在**覆盖层运行期间**且**光标停在按钮上**时存在，鼠标离开 / 按下鼠标 / 覆盖层关闭时 `KillTimer`；
- 覆盖层关闭后无任何定时器，待机路径完全不变（与 SYS-7 自动更新的一次性定时器同理）。

## 影响

- 覆盖层 `wndproc` 新增 `WM_TIMER` 分支；hover 状态、气泡几何与文案映射集中在 `overlay/toolbar/tip`，
  单文件规模可控。
- 气泡是**屏幕显示层**（同选中包围框、尺寸提示），不进导出烘焙，长截图与贴图都不受影响。
- 文案绑定 `Action` 后，未来新增按钮时漏写提示会落在 `match` 穷尽性检查上（编译期发现）。

## 未采纳方案

- **工具栏下方常驻一行状态条**：零延迟、信息稳定，但会常驻占掉 20 多像素高，且与
  「工具栏贴屏幕边缘翻上/翻下」的现有布局逻辑冲突。
- **鼠标旁跟随小标签**：不受工具栏边缘限制，但会挡住画面内容 —— 截图场景下直接盖住用户要截的东西。
  注意与现行方案的差别：气泡只**水平**跟随悬停控件，光标在按钮内移动时气泡不会移动。
- **按钮内嵌文字标签**：零交互零延迟，但工具栏宽度会翻几倍，小屏 + 窄选区放不下。
- **给颜色块显示「色名 + RGB」**：issue 举过这个例子，但 `editor::PALETTE` 只有色值没有名字，
  需要额外维护中文色名映射；本轮按「不加」处理，需要时再单独提。
