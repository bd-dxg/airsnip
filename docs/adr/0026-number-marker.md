# ADR 0026：序号标记（EDT-12）——徽标 + 引线箭头

- 状态：已采纳（v0.8.1 之后）
- 影响范围：`src/editor/`（`Kind::Number`、`Tool::Number`、变换 / 命中）、`src/render/`（徽标 + 引线 + 数字、
  半径缓存）、`src/overlay/`（起笔 / 拖动 / 自动编号 / 滚轮 / 二次编辑）、`src/overlay/toolbar/`、
  `src/settings/`（`ToolKeys.number`）、`assets/icons/ui/toolbar/number.svg`
- 相关：issue #82、EDT-12、EDT-8、EDT-11、ADR 0023

## 背景

issue #82 建议增加序号类标示（自动 1、2、3，或 ①②③），用于步骤图解、报错标注里的「第几步」。
PRD 原把它列在 EDT-8 候选工具。用户进一步明确：**徽标旁边要引出一个箭头**——按下鼠标在按下处出现徽标，
拖动方向出现箭头；并允许**二次编辑直接改编号**。

## 决策

1. 新增对象类型：

   ```
   Kind::Number { center, tip, n, font_size, radius }
   ```

   `center` 徽标圆心、`tip` 引线箭头尖端、`n` 编号、`font_size` 数字字号、`radius` 徽标圆半径。
2. **交互**：按下即在按下处放徽标（`tip == center`），拖动方向引出直线箭头（箭头沿终点方向、头部随线宽，
   复用直线箭头绘制）；按住 `Shift` 时引线方向吸附为水平 / 垂直 / 45°（与 EDT-2 箭头同一套 `snap_direction`，
   锚点为徽标圆心）；只点一下不拖也保留（只有徽标、无引线）。
3. **编号规则**：新建时取文档中已有序号的最大值 +1；删除 / 撤销**不重排**其余序号（「创建即定号」）。
4. **样式**：徽标实心圆取当前调色板色；数字按底色感知亮度自动取黑 / 白反色（否则白色调色板下白字不可见）；
   徽标圆随字号与编号位数放大；字号用滚轮连续调（悬停对象上时改该对象，空白处改默认值）。
5. **二次编辑**：双击徽标进入编号编辑，**复用文本输入状态机**（只收数字字符、最多 4 位、Enter 提交 / Esc 取消），
   提交时写回 `n` 并重算半径。
6. 其余一律沿用既有对象框架：命中 / 包围盒 / 平移 / 缩放（`remap`，字号随纵向比例）/ 方向键微调 /
   撤销重做 / 选中手柄 / 拖动通道（EDT-11、`objedit`），不新开交互通道。

### 半径缓存

徽标圆半径依赖「编号文本测量宽度」，而 `editor` 层是纯几何、不依赖 DirectWrite。沿用 `Kind::Text::size`
的约定：由渲染层 `number_radius(font_size, n)` 测量后写入 `radius` 字段；字号 / 编号变化后经
`render::text::remeasure` 重算。`editor` 的 `bounds` / `hit` 直接用缓存值。

## 未采纳方案

- **直接绘制 Unicode 带圈字符 ①②③**：超过 ⑳ 无对应字符，字体缺字时显示不一致；改为自绘圆底 + 阿拉伯数字
  （用户选择）。
- **独立递增计数器（只增不退）**：撤销后新建会跳号；取「文档内最大值 +1」更贴合直觉，且天然处理撤销。
- **删除后重排 1..n**：会让已画好的号发生变动，违背「创建即定号」（用户选择）。
- **拖拽决定徽标大小**：徽标大小改由字号（滚轮）控制，交互回到「按下放徽标 + 拖动出箭头」，与序号图解习惯一致。

## 影响

- 工具栏多一个工具按钮（`Tool::ALL` 6→7）；工具切换键新增默认 `7`，设置面板「快捷键」页多一行
  （快捷键行 10→11），冲突检测同步覆盖。
- 新增界面图标 `toolbar/number.svg`（Material Symbols `counter_1`，墨水率 29.9%，在 5%～48% 区间内）。
- 无新依赖；不改导出格式——序号对象随 `bake_objects` 烘焙进结果图，与屏幕显示一致。
