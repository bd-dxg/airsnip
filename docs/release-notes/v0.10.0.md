# AirSnip v0.10.0（功能 · 正式版）

v0.9.0 之后的版本：新增 3 个标注工具，颜色组改为 5 色全部可自定义，取消二次确认改为「连按两次」，并修复 HDR 桌面下长截图内存暴涨。

## 新功能

- **直线 / 椭圆 / 手绘自由笔画**（EDT-13/14/15，issue #134，ADR 0030）：工具栏新增三个标注工具，默认键 `8` / `9` / `0`（设置面板可改，参与冲突检测）。直线按住 `Shift` 吸附水平 / 垂直 / 45°，只有头尾两个端点手柄，拖动端点改向或拉伸；椭圆按住 `Shift` 画正圆，支持填充（与矩形共用填充开关），拖成纯横 / 纯竖的退化椭圆按误触丢弃（否则会留下看不见也选不中的对象）；手绘按 2px 最小步距采样点列、渲染用「相邻点中点 + 二次贝塞尔」平滑，命中按折线距离判定（看到的就是能点中的）。三者都进既有矢量对象模型，选中 / 移动 / 八向缩放 / 方向键微调 / 撤销重做自动可用。
- **5 个色块都可以自定义**（issue #122 / #123）：取消原来单独的「自定义色」格子，工具栏 5 个色块统一为**单击使用、双击改色**——双击展开覆盖层内自绘取色面板，改的就是该色块本身。单击不会产生选色延迟（第二击走 `WM_LBUTTONDBLCLK`，不需要计时器等「可能是双击」）。悬停提示显示当前色值（`#RRGGBB`）与操作方式。5 色随配置持久化（`swatch_colors`），旧配置的 `custom_color` 不再使用。

## 变更

- **取消改为「连按两次」**（issue #120，ADR 0027 后续）：有未保存标注时，第一次按 `Esc` / 右键只弹非模态提示，同一键在 2s 内再按一次才退出，不再弹系统确认框；换键或先做其它操作会解除待命。设置「常规」页开关文案改为「连按两次退出」，关掉后有标注也直接退出。
- **提示落点优化**：小选区下提示不再盖住大半个选区——优先放在选区内部右上角，可用高度不到提示两倍或宽度塞不下时退到上方，上方无空间则放下方，最后钳回屏幕内（2s 自动消失，末尾 0.5s 渐隐）。
- **系统对话框改用现代样式**：manifest 声明通用控件 v6，抓屏 / 保存失败等 `MessageBoxW` 提示不再是 Win7 式经典外观。
- 设置面板「快捷键」页键帽行 12 → 15 项（5 热键 + 10 工具），仍是两列排布、固定窗口高度内。
- 工具栏第一行 19 → 22 个按钮（100% DPI 下宽约 550 → 701px），已补窄屏 / 高缩放下不越界的回归测试。
- 体积：exe 1.43 MB → **1.44 MB**，zip 0.79 MB → **0.80 MB**（三个标注工具的实现与图标）。

## 修复

- **长截图 HDR 下内存暴涨**（issue #128，ADR 0029）：HDR 桌面抓屏走的是 DXGI Desktop Duplication，原实现每抓一帧就重建一次 D3D11 设备与 duplication 会话，而 NVIDIA 驱动在反复重建这一套时会累积内存泄漏（长截图期间每 ~90ms 一帧，越滚占用越大，报告者实测接近 15GB；关掉 HDR 走 BitBlt 则正常）。现改为**整个长截图会话复用同一套设备与 duplication**，会话结束统一释放；遇到 `DXGI_ERROR_ACCESS_LOST`（切换分辨率 / 全屏独占 / 锁屏）时重建一次后继续。单次截图与贴图编辑的区域抓取仍是现建现用，待机依旧不持有任何 D3D 设备。

## 说明

- 本版是**正式版**，v0.7.0 起的用户会通过自动更新收到（设置 → 关于 → 版本更新，或等托盘气泡提示）。
- 长截图期间会常驻一套 D3D11 设备（约几十 MB），这是修复的代价；不做长截图时仍然零开销。
- OCR 仍是**默认关闭**，需要到设置 →「OCR 翻译」打开总开关后才出现按钮与 `T` 键。
- 系统要求 **Windows 10 及以上（64 位）**，Windows 7 / 8 / 8.1 无法运行，原因见 README。
