# AirSnip v0.11.0（功能 · 正式版）

v0.10.0 之后的版本：**工具栏元素可以逐个隐藏**，界面只留自己常用的那几个按钮；**选中的标注可以单独删除**；OCR 不再有「先去设置里开总开关」这道门。

## 新功能

- **工具栏元素可逐个隐藏**（EDT-16，issue #143，ADR 0033）：设置面板新增「工具栏」页，24 个元素逐项显隐——工具 10 / 色块 5 / 填充·撤销·重做·字体行 / 贴图·长截图·OCR / 复制·保存；组头可整组全显 / 全隐（部分可见时勾选框显示半选）。**隐藏只是不画**：快捷键、输出行为、配置一律照旧——藏了保存按钮 `Ctrl+S` 照样能存，藏了椭圆数字键 `9` 照样能切过去。默认全部可见，所以不动设置的用户界面与原来完全一致；全部隐藏时工具栏整体消失（尺寸提示与出图不受影响）；新会话开始时若上次用的工具或当前色块被隐藏，自动落到第一个可见项。
- **选中的标注可以单独删除**（issue #71，ADR 0032）：选中对象后按 `Del` / `Backspace` 只删这一个，`Ctrl+Z` 一步恢复——不再需要「撤回到它之前、再把后面画的全部重画」。入口只有键盘（不加工具栏按钮，也不加包围框 ✕），没选中对象时不吞按键，照旧用于工具切换。

## 变更

- **OCR 不再有总开关**（issue #143）：OCR 常开，配置里的 `[ocr] enabled` 已删除（旧值忽略、不迁移），设置面板「OCR 翻译」页不再有「启用 OCR」。工具栏上的 OCR 按钮默认出现；不想看到它就在「工具栏」页隐藏按钮——**隐藏按钮不影响 `T` 键**，彻底不用 OCR 则到快捷键页把 OCR 键清空为「未设置」。待机开销不变：首次识别才初始化识别引擎。
- **设置面板新增「工具栏」页**：导航 6 → 7 项，五组统一 5 列紧凑排布，窗口高度不变（不引入滚动条）。文件组全部隐藏时页脚会提示「`Enter` 仍复制、`Ctrl+S` 仍保存」。
- **README 指标改为上限口径**：体积 / 内存 / 热键 / 帧率改成「单文件 < 2 MB」「待机内存 < 5 MB」「热键 ≤ 150 ms」「拖框 ≥ 60 FPS」，不再写会随版本漂移的精确值（精确数值仍在 `docs/perf-m5.md`）。头图换成展示 10 个工具与选中对象的实拍图。

## 修复

- **「恢复默认」按钮外点击会误触发**（issue #140）：命中测试原先用整行矩形判定，而行宽约 570px、按钮只有约 120px 且右对齐，于是按钮左侧一大片空白都会触发恢复默认；绘制侧又刻意取消了按钮行的整行悬停，视觉与实际可点区域正好相反。同一缺陷一并修好关于页的「版本更新」按钮。顺带把分散在 6 处的快捷键元数据（布局 / 键帽显示 / 冲突检测 / 写回 / 清空 / 二次确认）收敛成一张表，新增键帽行不再要手改 6 个平行 match（漏改会静默出错）。

## 说明

- 本版是**正式版**，v0.7.0 起的用户会通过自动更新收到（设置 → 关于 → 版本更新，或等托盘气泡提示）。
- 升级后工具栏会多出 **OCR 按钮**（以前要先去设置里打开总开关），不需要就在设置 →「工具栏」里隐藏。
- 已知边界：极端缩放组合（例如 1366×768 配 200%）下工具栏可能比屏幕还宽、右侧按钮被裁掉一角；在「工具栏」页隐藏不用的元素即可恢复，快捷键始终不受影响。
- 系统要求 **Windows 10 及以上（64 位）**，Windows 7 / 8 / 8.1 无法运行，原因见 README。
