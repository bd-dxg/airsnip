# AirSnip v0.11.1（修复 · 正式版）

v0.11.0 之后的补丁版，全部是问题修复加一处开关文案调整，没有新功能。

## 修复

- **贴图编辑时工具栏整条不出现**（issue #152 第 2 点，v0.11.0 回归，#153）：贴图窗口按空格或右键「编辑」进入标注编辑后，工具栏不显示，只有按 `3` 切到文本工具才整条冒出来。根因是判断「工具栏要不要重建」时，把「布局还不存在」当成了「不需要工具栏」——普通截图的工具栏由选区建立时顺带建好，而贴图编辑的选区是锁死的、不经过那条路径，工具栏只剩开局那一次建立机会，于是被直接跳过；切到文本工具后「需要第二行」使判断条件翻转，才连带把第一行建出来。现在「没有布局」一律重建，判据抽成纯函数并加单测守门。代价是元素被全部隐藏时每次按键/点击会多跑一次空布局（返回 `None`、不触发重绘）。
- **标注文字的输入法候选框不跟随光标**（issue #139，ADR 0034，#155）：标注文字是自绘的，窗口里没有系统 caret，程序也从未告诉输入法插入点在哪，于是微软拼音、清风输入法上候选框会乱飘、每次位置还不一样（对照组的 OCR 气泡用原生 `EDIT`，从来没这问题）。现在用 `ImmSetCandidateWindow`（`CFS_CANDIDATEPOS`）+ `ImmSetCompositionWindow`（`CFS_POINT`）把候选框锚到自绘光标：进入输入态、组合串变更、`WM_IME_STARTCOMPOSITION` 各上报一次，无定时器、不进重绘路径。**坐标必须用客户区坐标**，而且两个结构体要同时改口径才生效——第一版按屏幕坐标传，普通截图下恰好等价（覆盖层铺满虚拟屏、原点就是 0,0），但贴图编辑的小窗口坐在 `(814,463)` 这类位置时，候选框会整体偏出一个窗口原点的量。

## 变更

- **取消开关文案**（#160）：设置「常规」页的 `连按两次退出` 改为 `连按两次 Esc / 右键退出`。原标签既没说是哪个键、也没说触发条件，容易看不懂。行为完全不变：`Esc` 与右键共用同一套二次确认，时间窗仍是 2 秒（不是系统的双击间隔），没有未保存标注时一次就退出。

## 说明

- 本版是**正式版**，v0.7.0 起的用户会通过自动更新收到（设置 → 关于 → 版本更新，或等托盘气泡提示）。
- 未纳入本版的问题：原位贴图在多显示器上偏离原位置（issue #152 第 1 点，PR #158 待合）；长截图对 Windows Terminal 等 GPU 渲染窗口抓不到更新帧（issue #157）；截图时主屏黑屏（issue #156）尚在排查。
- 系统要求 **Windows 10 及以上（64 位）**，Windows 7 / 8 / 8.1 无法运行，原因见 README。
