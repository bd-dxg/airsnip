# AirSnip v0.12.0（功能 · 正式版）

v0.11.1 之后的版本：**框选完默认是移动态**，先摆好位置再选工具画标注；鼠标停在一个窗口上就**整窗高亮、单击选中**，还能再往下钻到具体的按钮 / 输入框；**OCR 与翻译正式撤销**。

## 新功能

- **窗口吸附**（CAP-6，issue #62，ADR 0037）：截图覆盖层里还没有选区时，光标停在哪个窗口上就高亮那个窗口（细边 + 半亮 + 尺寸提示），**单击即把整窗定成选区**，直接进入标注流程；按下就拖（超过 2px）仍退回原来的自由框选。窗口边界用 DWM 的 `EXTENDED_FRAME_BOUNDS` 取，不把 Windows 10 之后那圈看不见的缩放边框和阴影算进去。桌面壳窗口（`Progman` / `WorkerW`）不算候选——否则光标停在桌面空白上就整屏高亮、单击变成全屏截图；任务栏和 AirSnip 自己的贴图窗口则照旧可选。
- **控件级捕捉**（CAP-6 二级，issue #62，ADR 0039）：在整窗吸附之上继续下钻到 UI Automation 子控件——光标停在工具栏按钮、输入框、列表项上时高亮的是那个控件而不是整个窗口。悬停先亮整窗（立即可用），异步查到的子元素回包后再收紧；**候选上滚轮上 = 父级、下 = 更深**，最粗一档永远是整窗（实测有程序一个子元素都不给）。查询跑在常驻 worker 线程：目标程序假死时 UIA 调用会阻塞 10 秒，同步查会把整个覆盖层拖住。
- **框选完默认「移动选区」**（ADR 0036，issue #62 配套）：框选完成后直接就是移动态——选区内拖动 = 整体平移，拖对象本体 = 移动那个标注，方向键微调照旧；要画标注必须显式选工具（工具栏第一个「移动」按钮，或按 `V` 回到移动态）。**平移选区时标注跟着一起走**，不会被裁到框外。每次截图都从移动态开始（不再记忆上次用的工具），颜色 / 线宽 / 字号照旧记忆。
- **双击选区空白的动作可配**（ADR 0036）：默认仍是复制截图，可以在设置「通用」页改成直接贴到屏幕（等价 `F3`）。双击对象（编辑文本 / 恢复直线）、双击色块（取色面板）一律不受影响。

## 变更

- **撤销 OCR 与翻译**（ADR 0035，#163）：「AirSnip 轻截将撤销 OCR 与翻译功能，如需使用相关功能，请通过其他软件平替。」理由与实测结论见 ADR 0022 / 0035——提升识别精度或改走云端 API 必然增大体积，需求没有上限，与「轻量、常驻 ≈0 开销」的设计理念不符。连带变化：设置面板少一页（7 → 6，快捷键键帽行 16 → 15、工具栏可见性元素 24 → 23、输出组 3 → 2），`T` 键、`[ocr]` 配置段、`hotkey.ocr_key` 一并消失；无对外请求。
- **界面加入淡入**（ADR 0038）：按下截图键后覆盖层从桌面淡出（约 120ms），不再是硬切；动画结束立刻回到普通窗口，交互帧率不受影响，顺带消掉了首帧「已显示但还没画」的亮闪。
- **设置面板「通用」页两项改一行开关**：原来「贴图位置·原位置 / 屏幕中间」占两行单选，现在一行开关（开 = 屏幕中间、关 = 原位置）；开关与双击动作都是**点完立即生效并写盘**，不用关掉面板。
- **新增两个开关**：窗口吸附、控件级捕捉（默认都开），关掉后行为与没有这两项功能时完全一致。
- **工具栏「工具」组新增「移动」按钮**（第一位）：工具组 10 → 11 项，可见性元素 23 → 24 项。

## 修复

- **原位贴图在多显示器上偏离原位置**（issue #152 第 1 点，#158）：贴图载荷里是覆盖层画布坐标（原点在虚拟屏左上角），建窗时却当成屏幕坐标用——主屏不在左上时整体偏出一整块屏的量，再被限幅拉回主屏边缘。单屏、或主屏正好在左上时加法是恒等的，所以一直没暴露。
- **剪贴板贴图居中跨屏**（issue #152 追问，#166）：`F3` 贴剪贴板图时按理说该在当前显示器居中，原先却以**整个虚拟屏**为基准，主屏在右侧时中心落在两块屏的接缝上、贴图一半在左一半在右。现在按光标所在显示器居中；原位贴图仍按虚拟屏限幅（选区本来就可能跨屏）。
- **混合 HDR + SDR 多屏截屏时非 HDR 那块屏全黑**（issue #156，#162）：HDR 抓屏路径只把 HDR 输出贴进虚拟屏画布，画布初值是零，SDR 屏从头到尾没人填。现在遍历全部已连接输出：HDR 走 Desktop Duplication + 色调映射，SDR 按该屏矩形走 `BitBlt` 贴进同一张画布；「HDR 漏检」也从黑屏降级成该屏过曝。
- **设置面板开着时点托盘不置前**（#167）：面板是主线程上的模态消息泵，托盘消息能到主窗口，但防重入分支直接把「把窗口拿到前面」也一起吞了，只有面板真的关掉再点托盘才有反应。现在改为找回既有面板、最小化时先还原再抢前台。

## 说明

- 本版是**正式版**，v0.7.0 起的用户会通过自动更新收到（设置 → 关于 → 版本更新，或等托盘气泡提示）。
- **升级后 OCR 与翻译、以及 `T` 键不再存在**；需要取字或翻译请用其他软件。
- **多显示器的三处修复都没有真机多屏环境验证**（开发机单屏），单测只守住坐标算术。有多屏的用户若仍有偏差请回报，附上显示器排布截图。
- 未纳入本版：长截图对 Windows Terminal 等 GPU 渲染窗口抓不到更新帧（issue #157，四种抓屏后端实测均拿不到更新帧，排查结论待单独提交）。
- 已知边界：极端缩放组合（例如 1366×768 配 200%）下工具栏可能比屏幕还宽、右侧按钮被裁掉一角；在设置 →「工具栏」隐藏不用的元素即可恢复。
- 系统要求 **Windows 10 及以上（64 位）**，Windows 7 / 8 / 8.1 无法运行，原因见 README。
