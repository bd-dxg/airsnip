# AirSnip v0.13.0（功能 · 正式版）

v0.12.0 之后的版本：涂色多了**渐变**、描边多了**虚线 / 点划线**；截完图按 **`Alt+S`** 就按模板直接落盘，不用再点对话框；没有选区时 **`F` 一键选整屏、`R` 复用上次区域**；设置「关于」页多了「我要反馈」，一键把运行环境写进剪贴板。

## 新功能

- **标注渐变**（EDT-19，issue #168 后续，ADR 0043）：工具栏颜色组从 5 个纯色改成 **2 纯色 + 1 渐变**。渐变色块格子画的是径向预览，**单击使用、双击换一套**（24 套色相各不相同、方向正反交替，不会每次都一样）；一套是**完整光谱**（赤橙黄绿青蓝紫 + 闭合点共 8 个色标、色相跨 360°），在 **OKLab 感知空间**里插值、整体亮度统一（暗底上不发浑），**首尾闭合**所以描边绕一圈不会在角上留硬接缝。描边沿**周长弧长**走色（直角矩形特判 4 条边、每边一次描边，不再是近百次），填充按包围盒长边，箭头 / 直线沿起点→终点。
- **标注线型**（EDT-18，issue #168，ADR 0042）：「填充」右侧新增线型格子（当前线型的真实样本 + ▾），三档 = 实线 / 虚线 / 点划线，段长按线宽缩放、虚线用平头端点。线型是**对象样式**：选中对象后改立即生效并进一次撤销，没有选中时只影响下一次绘制；只对有可见描边的对象（矩形 / 椭圆 / 箭头 / 直线 / 手绘 / 序号引线）生效，填充对象、文本、荧光笔、模糊、聚光灯选中时格子置灰。
- **快速保存 + 保存路径模板**（OUT-2，ADR 0041）：覆盖层内按 **`Alt+S`** 直接按模板落盘、不弹对话框（`Ctrl+S` 另存为照旧，现已可在快捷键页改键）。模板 = 目录（点一下用资源管理器选）+ 文件名（面板内直接改）+ 格式（png / jpg / webp），支持 `$yyyy$ $yy$ $MM$ $dd$ $HH$ $mm$ $ss$ $ts$` 与 `%VAR%`；同名默认**自动加序号**，目录不存在自动创建，模板写坏会在写盘前拦住并保留覆盖层可重试。存完覆盖层内弹一条轻提示，**点提示直接定位到文件**；可选「同时复制到剪贴板」。预览与保存共用同一渲染器，所见即所存。
- **快速选区键 `F` / `R`**（ADR 0040）：没有选区时按 **`F`** 选中**光标所在显示器**的整屏（含任务栏，多显示器下鼠标在哪块屏就框哪块），按 **`R`** 复用**本次运行**上一次确定的选区。两者都只选中、不自动完成 —— 落下后接着标注或按 `Enter` 都行；已有选区（或贴图编辑模式）时按下去什么也不做。
- **「我要反馈」**（SYS-8）：设置 →「关于」行右侧新增按钮，一键把版本号、Windows 版本与 build、显示器（分辨率 / 缩放 / 相对主屏位置 / HDR）、显卡、关键开关按三行文本写进剪贴板，随后弹一条通知；**只有点通知上的「打开反馈页」才跳转浏览器**（不点约 4 秒自动消失，避免你在网页上再被跳一次）。不收集用户名、保存路径与截图内容。

## 变更

- **工具栏颜色组 5 格 → 3 格**：旧配置的 5 个色块**取第 2、3 项**迁移成新的两个纯色，其余丢弃 —— 升级后建议到设置里重新确认一下颜色。
- **设置 → 保存页重做**：三个「命名方式」单选退役，改为「保存路径模板」（目录 / 文件名 / 格式 / 同名处理 / 预览 / 打开文件夹 / 变量说明）。这是设置面板第一次出现**自绘单行输入框**：支持 `Ctrl+V` 与输入法（候选框跟随光标），暂不支持选中文字与鼠标定位光标（点框 = 光标到末尾）。
- **快捷键页拆成三个子页签**：截图（4 项）/ 输出（5 项）/ 工具（11 项），20 项仍全局参与冲突检测；新增「保存」`Ctrl+S`（原先硬编码）与「快速保存」`Alt+S`。
- **工具栏新增「快存」按钮与线型格子**：文件组 2 → 3 项、编辑组 4 → 5 格。**1366×768 @ 200% 又重新放得下**（更小的屏仍可能右侧被裁，可在设置「工具栏」隐藏不用的元素）。
- 设置面板主界面下拉改为「真下拉」（点开列表 → 点选项生效 → 点列表外或 `Esc` 收起，展开期间吞掉点击不穿透）；面板高度 524 → 520。

## 修复

- **渐变手绘第二条起卡顿**（#192）：渐变描边原先对「贝塞尔细分后的每一小段」都单独描一次边（一条 1200px 的笔迹约 4000 次），落笔成对象后每次重绘还要整条重描，于是第一条流畅、第二条起肉眼可见地掉帧。改为按**整条路径的累计弧长**每 8px 描一小段（约 150 次），帧耗时 72ms → 9.2ms，与纯色绘制持平；椭圆 / 圆角矩形的渐变描边一并受益。

## 说明

- 本版是**正式版**，v0.7.0 起的用户会通过自动更新收到（设置 → 关于 → 版本更新，或等托盘气泡提示）。
- 升级后**颜色组少两个色块**、快捷键页位置重排（见「变更」），其余配置照旧读取。
- 未纳入本版：长截图对 Windows Terminal 等 GPU 渲染窗口抓不到更新帧（issue #157）、长截图存剪贴板后读出有误（issue #189）、「拼接定位失败」提示（issue #129）、国际化一期（issue #151）。
- 系统要求 **Windows 10 及以上（64 位）**，Windows 7 / 8 / 8.1 无法运行，原因见 README。
