# AirSnip v0.14.0（功能 · 正式版）

v0.13.0 之后的版本：长截图**更靠得住**（页面里有轮播图 / GIF 头像也能拼、粘滞侧栏不再重复、白底页面滚动不再被判「静止」），批注能标**对勾 / 叉号**，长截图日志默认就写——遇到问题点一下「打开日志文件夹」把文件发出来就行，不用再碰环境变量。

## 新功能

- **对勾 / 叉号徽标**（EDT-20，issue #186，ADR 0045）：序号标记升级成**徽标**，内容三态 = 数字 / 对勾 / 叉号，用来标「这里对、这里错」。**没有新增工具栏按钮**（第一行宽度已经贴着 1366×768 @ 200% 上限）：序号格子右下角多了个 ▾，点它弹三行下拉选形态；符号**不占用编号**——一张图里混放 `1`、`✓`、`✕`、`2` 仍是 1、2。符号用矢量描边画、不用字符，换成任何字体都不会变成豆腐块，和徽标的圆形比例也始终一致。
  - 放置后要改：**符号徽标双击直接在对勾 / 叉号之间切换**（一次 `Ctrl+Z` 可回退，比开输入框少三步）；**编号徽标双击仍进编辑框**，可以直接打 `v` / `√` / `✓` 或 `x` / `×` / `✕`，**不需要输入法**，且以最后输入的那个有效字符为准。
- **长截图日志常开 + 一键打开日志文件夹**（SYS-9，issue #200，ADR 0046）：以前排查长截图问题要退出托盘、开 PowerShell、设 `AIRSNIP_DEBUG=1` 再启动、去 `%TEMP%` 里翻文件；现在**日志默认就在写**，设置 →「通用」页底部点**「打开日志文件夹」**就能拿到（`%TEMP%\airsnip\`）。
  - 日志只有状态文本（滚动位置、匹配得分、画面变化比例），**不含页面内容、不含账号密码**；超过 4MB 自动轮转成 `.log.1`，只保留最近一段。
  - 定位异常时会把两帧画面存成 PNG（每次运行最多 6 对），用来判断「页面真的没动」还是「抓到的是旧帧」；问题解决后随手删掉即可。

## 修复

- **长截图定位失败与粘滞侧栏重复**（issue #129 / #196 / #157 第 2 点，ADR 0044）：
  - 页面里有**局部动画**（轮播图、GIF 头像、闪烁光标、进度条）时不再整段失败——每行切 8 段各算哈希，5 段一致即算这行没变，动画只影响它所在的那一小段；
  - **快速滚动**（超过半屏）也能接上：重叠区的最小要求从「半个内容区」放宽到 1/5，并且所有候选位移都参与打分取最优（原来第一个达标就停）；
  - **白底 / 内容稀疏的页面**一滚动就被判「静止」的毛病修好了（旧写法把「位移 0 得分低」和「页面几乎空白」混成同一个分支，结果后面的候选位移一个都不试）；
  - **吸顶导航 / 底部工具栏**原来会被重复拼进每一段，现在只留在最上面一份；**左右粘滞侧栏**（论坛话题侧栏、时间轴）同理，且纯色列不会被误遮；
  - 失败不再丢内容：参考帧只跟着「成功拼入」前进，滚太快定位失败时往回落一点就能接上。

## 变更

- **长截图状态条**按钮补齐悬停反馈：停留 400ms 弹出「名称 · 快捷键」气泡，悬停有底色，完成 / 取消的图标样式与覆盖层工具栏统一（`longshot/tip.rs`）。

## 说明

- 本版是**正式版**，v0.7.0 起的用户会通过自动更新收到（设置 → 关于 → 版本更新，或等托盘气泡提示）。
- 长截图出问题时的报障方式变了：**不用提前开任何开关**，点「打开日志文件夹」把 `airsnip-longshot.log`（必要时加 `airsnip-longshot-*.png`）附到 issue 里即可。
- 未纳入本版：长截图对 Windows Terminal 等 GPU 渲染窗口抓不到更新帧（issue #157 的抓屏部分）、长截图存剪贴板后读出有误（issue #189）、国际化一期（issue #151）、箭头「起点窄终点宽」样式（issue #197）。
- 系统要求 **Windows 10 及以上（64 位）**，Windows 7 / 8 / 8.1 无法运行，原因见 README。
