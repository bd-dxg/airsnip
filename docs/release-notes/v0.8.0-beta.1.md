# AirSnip v0.8.0-beta.1（OCR · 预发布）

本版新增 **OCR** 文字识别。识别走 Windows 自带的 `Windows.Media.Ocr`，图片不出本机，不需要 API key，不联网，也不计费。

因为功能刚落地，先按预发布放出，验证够了再转正式版。

## 新增

- **OCR 文字识别**：`F1` 框选后按 `T`（或点工具栏「OCR」按钮），覆盖层立即关闭，弹出文字卡片。
  - 卡片可直接改错字、拖选、`Ctrl+A/C/V/X/Z`、右键菜单；输入法候选框跟随光标；`Esc` 或 ✕ 关闭。
  - 左下「复制」一键写剪贴板，右下「自动复制」开关默认关闭；顶部图钉把卡片置顶，方便对照粘贴。
  - 卡片不自动关闭，什么时候关由你决定。
  - **默认关闭**：设置 →「OCR 翻译」里打开总开关后才生效。关闭时工具栏不出现 OCR 按钮、`T` 键不生效、不初始化任何识别组件。
  - 识别语言默认跟随系统首选语言，也可在设置里固定为某个已安装的语言包。
- **快捷键支持 PrintScreen**（#67）：`PrtScn` 此前点了键帽后按没反应 —— 系统只派发松键消息、没有按下消息，现在改为在松键时捕获。顺带补齐了 `Pause`、`Backspace`、`CapsLock`、`Home`、`End`、`PgUp`、`PgDn`、`Insert`、`NumLock`、`ScrollLock` 的键名显示。
- **鼠标中键 / 侧键可当热键**（#78）：截图、贴图、贴图边框都能绑到鼠标中键与两个侧键。用 Raw Input 订阅，不走低级鼠标钩子（钩子每次鼠标移动都要跨进程回调，超时会被系统静默卸载）。
- **工具栏悬浮提示**（#70）：鼠标在按钮上停约 400ms 弹出气泡，显示「名称 · 快捷键」；改键后提示跟着变。选中对象后悬停右上角小圆也会提示「圆角 · 拖动调节」。

## 修复

- **静态链接 MSVC 运行时**：此前 exe 依赖 `VCRUNTIME140.dll` 与 `api-ms-win-crt-*.dll`，没装 VC++ 运行库的机器双击会报「找不到 VCRUNTIME140.dll」。现在改为静态链接，开箱即用。打包脚本新增 PE 导入表校验，防止这个依赖被悄悄带回来。

## 变更

- 文字卡片的文本区改用 Windows 原生编辑控件：之前自绘的版本虽然能用，但输入法候选框不会跟着光标走，也没有右键菜单与撤销。
- 功能名从「取字」统一改为「OCR」。
- 体积：exe 1.21 MB → **1.38 MB**，zip 0.67 MB → **0.77 MB**（静态运行时 +128 KB，OCR 模块与 WinRT 依赖 +50 KB）。

## 已知限制

- **需要系统语言包**：设置 → 时间和语言 → 语言和区域 → 对应语言 → 可选功能里装「光学字符识别」。没装时卡片会直接说明缺哪个语言包，不会静默识别成乱码。
- **只认屏幕渲染的文字**：清晰、字号稳定的文本效果最好；艺术字、彩色背景、极小的字会掉识别率。
- `）` 偶尔会被认成 `冫`，属于引擎的标点误识，暂未做后处理。
- 单次选区最长边不能超过 10000 像素。
- 内容超过约 44 行时卡片内部可滚动，但没有可见滚动条（滚轮能滚）。

## 说明

- **本版是预发布，不会自动更新到你**。GitHub 的 `releases/latest` 只指向正式版，现有 v0.7.0 用户的自动更新查到的仍是 v0.7.0。想试 OCR 请手动下载本页的 zip。
- 觉得不稳可以随时装回 [v0.7.0](https://github.com/bd-dxg/airsnip/releases/tag/v0.7.0)，配置目录不变，OCR 的开关会保留但不生效。
- 识别错的地方反馈时最好带上截图，方便判断是引擎能力问题还是我们喂错了图。
