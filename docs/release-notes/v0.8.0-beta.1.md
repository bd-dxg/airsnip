# AirSnip v0.8.0-beta.1（取字 · 预发布）

这是**取字**功能的第一个公开测试版。识别走 Windows 自带的 `Windows.Media.Ocr`，图片不出本机，不需要 API key，不联网，也不计费。

## 新增

- **取字**：`F1` 框选后按 `T`（或点工具栏「取字」），覆盖层立即关闭，弹出文字卡片。
  - 卡片可改错字、拖选、`Ctrl+A/C/V/X/Z`、右键菜单，输入法候选框跟随光标；`Esc` 或 ✕ 关闭。
  - 左下「复制」一键写剪贴板，右下「自动复制」开关默认关闭；顶部图钉把卡片置顶，方便对照粘贴。
  - 卡片不自动关闭，什么时候关由你决定。
- **默认关闭**：设置 →「取字翻译」里打开总开关后才生效。关闭时工具栏不出现取字按钮、`T` 键不生效、不初始化任何识别组件。
- **识别语言**：默认跟随系统首选语言，也可在设置里固定为某个已安装的语言包。

## 变更

- 文字卡片的文本区改用 Windows 原生编辑控件：之前自绘的版本虽然能用，但输入法候选框不会跟着光标走，也没有右键菜单与撤销。

## 已知限制

- **需要系统语言包**：设置 → 时间和语言 → 语言和区域 → 对应语言 → 可选功能里装「光学字符识别」。没装时卡片会直接说明缺哪个语言包，不会静默识别成乱码。
- **只认屏幕渲染的文字**：清晰、字号稳定的文本效果最好；艺术字、彩色背景、极小的字会掉识别率。
- `）` 偶尔会被认成 `冫`，属于引擎的标点误识，暂未做后处理。
- 单次选区最长边不能超过 10000 像素。
- 内容超过约 44 行时卡片内部可滚动，但没有可见滚动条（滚轮能滚）。

## 说明

- **本版是预发布，不会自动更新到你**。GitHub 的 `releases/latest` 只指向正式版，现有 v0.7.0 用户的自动更新查到的仍是 v0.7.0。想试取字请手动下载本页的 zip。
- 觉得不稳可以随时装回 [v0.7.0](https://github.com/bd-dxg/airsnip/releases/tag/v0.7.0)，配置目录不变，取字的开关会保留但不生效。
- 识别错的地方反馈时最好带上截图，方便判断是引擎能力问题还是我们喂错了图。
