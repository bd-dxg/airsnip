# AirSnip v0.8.1（修复 · 正式版）

v0.8.0-beta.1 之后的收尾版本，全部是问题修复，没有新功能。OCR 随本版转为正式发布。

## 修复

- **HDR 桌面截图过曝发白**（#75）：HDR 显示器上截出来的图整体发白。原因是 HDR 激活时桌面是 FP16 scRGB 色彩空间，用老的 `BitBlt` 抓到的是被当成 sRGB 的线性高亮度值。现在 HDR 激活时改用 **DXGI Desktop Duplication** 抓 FP16 scRGB 帧，再按显示器的 SDR 白点做色调映射，整屏纯白像素占比从 23.37% 降到 0.06%。HDR 未激活时仍走原来的 BitBlt 快路径（长截图的区域抓取一并覆盖）。色调映射用 64 KB 合成查表，2560×1440 抓屏 127–173ms → 80–103ms。决策见 ADR 0024。
- **标注无法画在已有图形上**（#93/#100）：用聚光灯框住一片区域后，换荧光笔在该区域内拖拽什么都画不出来（鼠标还变成移动光标）。原因是按下时命中判定只有「整块命中就移动」一条通道。现在对象内部按下改为**绘制**（拖动画新标注、无位移松手则选中），移动对象改走 `Ctrl` + 拖动本体或拖包围框边缘（方向键微调不变）。决策见 ADR 0023。
- **F10 等系统键热键在截图状态失效**（#90）：F10 是系统菜单键，`Alt` + 键也走 `WM_SYSKEYDOWN`，此前只处理 `WM_KEYDOWN`，把截图 / 贴图 / 长截图 / OCR 热键设成 F10 时在覆盖层里完全没反应。现在覆盖层新增 `WM_SYSKEYDOWN` 分支，只接管未按 `Alt` 的动作键，`Alt+F4` / `Alt+S` 等组合仍透传给系统。
- **系统深 / 浅色切换后设置面板不跟随**（#91）：选「跟随系统」却在切换深浅色时面板不变。现在面板自己处理 `WM_SETTINGCHANGE`，并额外用 `RegNotifyChangeKeyValue` 监听注册表兜底（管理员进程可能被 UIPI 挡住用户级进程的主题广播），事件驱动、不做轮询，同步更新 DWM 深色标题栏。
- **托盘图标重试窗口过短**（#77/#99）：此前 `NIM_ADD` 失败后只重试 5 秒。实机里 explorer 曾比 AirSnip 晚启动 114 秒，窗口一过图标就永久缺失。重试窗口放宽到 **3 分钟**（36 次 × 5 秒），仍是失败才挂计时器、成功即撤销，不引入常驻轮询。

## 变更

- 功能名「取字」统一改为「OCR」（#87）：设置面板页签「取字翻译」→「OCR 翻译」、气泡标题「AirSnip 取字」→「AirSnip OCR」、工具栏按钮悬浮提示补全。`[ocr]` 配置段与字段名本就是 `ocr`，无需迁移。
- 校正 README / AGENTS / PRD 等文档里的过期数据与系统要求说明（#86/#88/#95/#96/#102）。

## 说明

- 本版是**正式版**，v0.7.0 起的用户会通过自动更新收到（设置 → 关于 → 版本更新，或等托盘气泡提示）。
- OCR 仍是**默认关闭**，需要到设置 →「OCR 翻译」打开总开关后才出现按钮与 `T` 键。
- 系统要求 **Windows 10 及以上（64 位）**，Windows 7 / 8 / 8.1 无法运行，原因见 README。
