# AirSnip v0.9.0（功能 · 正式版）

v0.8.1 之后的版本：新增 3 项标注能力，修复 3 个问题。

## 新功能

- **序号标记**（EDT-12，issue #82，ADR 0026）：新增「序号」标注对象——按下放圆形徽标、拖动引出箭头（按住 `Shift` 吸附水平 / 垂直 / 45°）。自动编号（取已有最大值 +1，删除 / 撤销不重排），双击徽标可直接改编号；颜色跟调色板、滚轮连续调大小，数字按底色自动取反色。工具栏新增「序号」按钮，工具切换键默认 `7`。
- **自定义标注颜色**（EDT-7，issue #73）：工具栏颜色组在 5 个预设色块后新增一个自定义色块，点击展开**覆盖层内自绘取色面板**（色相条 + 饱和度 / 明度方块 + 2×6 快捷色块），取代不适用的系统取色对话框。拖动实时预览选中对象、松手记为一步撤销；与字体面板互斥。自定义色写回配置，下次截图沿用。
- **贴图按空格进入标注编辑**（issue #56，ADR 0028）：贴图窗口聚焦按 `空格` 或右键菜单「编辑」，即复用截图工具栏就地补画标注（覆盖层临时做成只包住「贴图 + 工具栏」的小窗口，不抓整屏、不暗化）。完成（`Enter` / `空格` / 选区内双击）把结果写回**同一张贴图**、缩放复位 100%；取消 / 复制 / 保存则原样恢复。贴图右键「保存」同时改为原生另存为对话框（复用命名模板与上次目录）。

## 修复

- **截图无法粘贴到飞书**（#107，ADR 0025）：剪贴板 `CF_DIB` 由自上而下（负 `biHeight`）改为自下而上（正 `biHeight`），写入时逐行反转像素，并补全 `biSizeImage`。统一为 GDI 与主流截图工具的 DIB 写法，飞书可粘贴且微信不受影响。
- **设置面板比例失真**（#109）：设置窗口恢复固定 720×520 不再被内容撑高；快捷键页改两列排布（12 项 → 6 行）。「恢复默认」改为右侧真按钮，清除（垃圾桶）图标仅在悬停 / 捕获态显示，行悬停改圆角矩形并四周留白。
- **右键误触直接退出截图丢失标注**（#113，ADR 0027）：`Esc` / 右键取消改为分层回退——先收面板，再处理文本输入，最后才退出；有未保存标注时先弹确认框（点「否」可继续）。文本 / 序号输入中右键 = 完成输入（保留文字）。
- **复制文字后按贴图键弹错误框**（issue #56 第 2 点）：剪贴板无图片格式时改为静默忽略，不再弹错误框。

## 变更

- 工具栏选中颜色由蓝色描边改为**色块自身发光**（纯 CPU 叠 7 层低透明度圆角矩形，随 DPI 缩放，#112）。
- 拆分 6 个超 300 行的源文件（`annotate` / `panel::interact` / `toolbar::tip` / `app::mod` / `interaction::mod` / `textinput`），语义等价（#101）。
- 体积：exe 1.40 MB → **1.43 MB**，zip 0.78 MB → **0.79 MB**（新增序号 / 取色面板 / 贴图编辑相关代码）。

## 说明

- 本版是**正式版**，v0.7.0 起的用户会通过自动更新收到（设置 → 关于 → 版本更新，或等托盘气泡提示）。
- OCR 仍是**默认关闭**，需要到设置 →「OCR 翻译」打开总开关后才出现按钮与 `T` 键。
- 系统要求 **Windows 10 及以上（64 位）**，Windows 7 / 8 / 8.1 无法运行，原因见 README。
