# AirSnip v1.0.0（功能 · 正式版）

v0.14.0 之后的版本，也是第一个 **1.0**：界面支持**四门语言**（简体中文 / 繁體中文 / English / 日本語），切换立即生效；**普通权限账户不再被 UAC 卡在启动前**——公司 / 学校统一管理的电脑上也能直接用；关于页标明了唯一官方下载渠道与退款说明。

## 新功能

- **四门语言**（I18N-1..5，issue #151，ADR 0047）：简体中文、繁體中文、English、日本語，设置 →「通用」→「语言」选完**立即生效**（纯查表，界面不重开、不闪烁）。
  - 默认「跟随系统」。简体中文系统照旧是简体中文；**不支持的系统语言一律回落 English**，非中文用户第一次打开不会看到一屏中文。
  - 界面文案全部进了语言表（编译期嵌入），**不会有漏翻的硬编码中文**：漏一条是编译错误，而不是界面上突然冒出一句中文。
  - 四门语言各用系统自带的首选界面字体（YaHei / JhengHei / Segoe UI / Yu Gothic UI）；**标注内容字体不跟着界面语言变**——导出的图不该因为换个界面语言就变样。
  - 布局按文字实际宽度自适应（工具栏中文 5 列、英日 4 列，行高按可用高度收缩），不是写死 `if 语言`。长截图状态条对四门语言的文案逐条量过宽，最窄的条下仍留约 70px 余量。

## 变更

- **权限按账户能力取最高**（SYS-4，issue #198，ADR 0048）：manifest 从「强制管理员」改为 `highestAvailable`。
  - 管理员账户**行为完全不变**（照旧自动提权，能截取管理员窗口）。
  - 标准账户（公司 / 学校统一管理、拿不到 UAC 凭据）**不再卡在启动之前**，以普通权限直接运行。代价是截不到以管理员身份运行的程序窗口（UIPI 限制），启动时会弹一次托盘气泡说明原因。
  - 开机自启任务的权限级别跟随当前账户（`HIGHEST` / `LIMITED`）；「我要反馈」的系统信息里也带上了当前权限，方便判断「截不到 / 盖不住」属于哪一类。
- **关于页标明官方下载渠道**（#217）：新增「官网·永久免费」一行（[airsnip.bddxg.top](https://airsnip.bddxg.top)），底部一条小字提示「软件免费·第三方购买·请向卖方申请退款」。原因很直接——GPL-3.0 允许第三方**原样打包收费再分发**，技术上防不住；能做的只是让拿到打包版的用户知道「官方版本是免费的」这一件事。

## 修复

- **长截图遇到半透明窗口给出针对性提示**（issue #157，#216）：抓到半透明 / 分层窗口时拼接会失败，现在直接告诉你是哪一类窗口，而不是只报一句「定位失败」；根因同时记进日志（`%TEMP%\airsnip\`，设置 →「通用」→「打开日志文件夹」）。

## 说明

- 本版是**正式版**，v0.7.0 起的用户会通过自动更新收到（设置 → 关于 → 版本更新，或等托盘气泡提示）；清单验签与 SHA-256 校验机制不变。
- **1.0 的含义**：功能面（截图 / 10 个标注工具 / 长截图 / 贴图 / 四门语言 / 自动更新）按设计完成，后续以打磨与修 bug 为主，不排除继续加功能。
- 已知边界（不打算在 1.0 内解决）：
  - **繁體中文与日本語文案未经母语者校对**——措辞别扭欢迎在 issue #151 指出。
  - 长截图对 GPU 渲染窗口（Windows Terminal、部分 Electron 应用）仍抓不到更新帧（issue #157 的抓屏部分），四种后端实测结论记录在 [docs/longshot-known-issues.md](../longshot-known-issues.md)。
  - 长截图存剪贴板后读出有误（issue #189）；箭头「起点窄终点宽」样式未做（issue #197）。
